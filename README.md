## 📖 About This Project

Python began as a holiday project by one frustrated programmer in 1989.  
Today it powers ChatGPT, Instagram, NASA tools, and millions of applications worldwide.

This audit asks — *why does Python exist, who built it, what freedoms does its  
license actually give you, and how does it live on a Linux system?*

The project includes a full written report and five shell scripts that explore  
Python through the Linux command line.

## 🛠️ Shell Scripts

| # | File | What It Does |
|---|---|---|
| 1 | `Script 1` | Displays a system identity report — kernel, user, uptime, distro, and license info |
| 2 | `Script 2` | Checks if Python is installed and prints a philosophy note using a case statement |
| 3 | `Script 3` | Audits key system directories for permissions, ownership, and size |
| 4 | `Script 4` | Analyzes a log file and counts keyword occurrences using a while-read loop |
| 5 | `Script 5` | Interactively generates a personal open source manifesto and saves it to a file |
